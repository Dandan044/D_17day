# 文案声音：贴地，不要「AI 味」

本文件是给人和后续 AI 的同一份约束。写玩家看得见的中文时先读完再动手。

游戏已有自己的声音。旧内容（情报、站点、准备期邻居、日常敲门）已经成立。后补事件把这个调做成了公式：先否定再揭示、短句排比、抽象收尾。玩家读完不知道眼前发生了什么，只觉得「写得很文学」。

目标不是把文学铲平，而是让每一句都能回答：**现在在哪，手上是什么，发出什么声。**

## 四条原则

1. **先写场面。** 谁、在哪、手上是什么、发出什么声。主题让场面自己带，不要收成金句。
2. **一句只做一件事。** 禁止把「不是 X。是 Y。」当成默认开头。禁止用「X 也是一种 Y」收尾。
3. **比喻必须能摸到。** 黄纸、门缝、盆底细灰可以。缝、层次、节奏、版本、法庭、葬礼不当主语。
4. **选项写动作，日志写结果。** 不写「选择也是一种关」。玩家点按钮时要知道自己在干什么。

「不是 X，是 Y」本身不该死。洪灾说明「你听见的第一个声音不是水，是汽车报警器」能留：Y 具体、意外、看得见。坏的是把它当流水线，并且 Y 是抽象词。

**揭晓、高潮、结局收束另有一条。** 玩家读完必须能说出发生了什么物理事件。禁止用空隐喻顶替事实：

| 禁写 | 为什么坏 | 改成 |
|---|---|---|
| 那种从地底传来的、不像声音的声音。 | 读完不知道是什么 | 整栋楼都在抖，防盗门嗡嗡响。 |
| 没有人宣布任何事情。但所有人都明白了。 | 金句收束，没交代明白了什么 | 楼道里有人喊"核爆了"，有人只是把门反锁。 |
| 都不重要。 / 秩序就是这么没的。 | 作者跳出来总结 | 第三天，路口已经没有交警。 |
| 这屋里有了一种不会消失的东西。 | 抽象主语，读者要对号入座 | 那两份罐头没有回来。 |

灾难揭晓尤其危险：这段是玩家第一次确认「来的是什么」。先写光、声、电、雨、人说了什么，再停。不要写「所有人都明白了」。

| 2 | **短陈述** | **陈述**单独成句 < 2 字禁，= 3 字谨慎。非陈述（`也行。`）允许 | 并进上句 / 补足成完整陈述 |

| 4 | **说书腔（打比方）** | 「这句话我会不会说出口？」禁「等于 X」「像 X 一样」「跟 X 似的」 | `靠，昨晚发电机响了一整夜。` |

| 6 | **抽骨头** | 主语在吗？具体名词在吗？**少任何一个都是电报** | `没人收` → `没人收尸` |
| 7 | **脏话过头** | 低强度不出 `操`；强度 4 全篇最多一次；冷漠场面不骂 | 见「第二轮之六」 |
| 8 | **重写好句子** | 原文主干能不动就不动 | 改造 = **加**（人称 / 情绪载体）+ **删**（选项行动 / 作者评论） |

**第 6 条特别警告**：`尸` `血` `冻硬` `臭` `烂` —— 残酷场面的具体名词是**承重墙**，
最容易犯的错就是觉得它们"不雅"而磨掉。**`没人收尸` 里 `尸` 没有替代品。**

**第 8 条是反复出错的根因**：改造的默认动作应该是**加**，
而不是把原文改短、改口语、调语序。加的三类手法：

| 手法 | 例 |
|---|---|
| **多余的话** | `我数着的。` · `数到六十干什么呢。` |
| **私人经验的钩子** | `那不是猎枪的声音。猎枪我听过。` |
| **当下反应代替事后归纳** | 保留 `只为确认炉子还能用` + 加 `壶叫起来那一下，我心里松了松。` |

这些句子都出现过。不要再写同类的。

| 禁写 | 为什么坏 | 改成 |
|---|---|---|

| 停不等于否。停是一种更长的句子。 | 「X 是一种 Y」格言 | 消息停了。停了不等于他们不在了，只是你再也等不到下一条。 |
| 空也是一种到达。 | 同上 | 车队的消息是假的。你还在这间屋子里。 |
| 选择也是一种关。 / 原处也是一种藏。 / 响也是一种清点。 | 把动作收成定义 | 写你做了什么、看见了什么 |
| 屋子承认你来过。 / 呼号在纸上睡觉。 / 包比你冷静。 | 物件拟人当收束 | 木屑换了位置。电台关着。包还在门口。 |
| 睡眠变成一种需要许可的事。许可得你自己发。 | 意识流，场面丢了 | 你躺下又坐起来。上一回数管道，上上回听楼道。 |
| 记忆却为一种没有发生的逃法留了座位。 | 读不懂 | 城里没发大水。那条船的停靠点你还记得，用不上。 |
| 拧开盖时屋里只有你一个人。 | 场面写完后再加的废话收束 | 盖口有一点皂味，煮开也散不干净。 |
| 手指黑的。 / 没有大人。电梯口的告示牌倒在地上。 | 两字砸点 + 不改变选择的气氛 | 手指全是灰。电梯口的告示牌倒在地上，灰在上面也有一层。 |
| 你听见自己的呼吸。 / 人还在屋里。 | 气氛收束，没有结果 | 写门链、水位、灰、纸——物去了哪 |

不要用这些词当句子的主语或收束：缝、空白、层次、节奏、版本、法庭、葬礼、许可、形状、到达、清点。

不要批量使用：

- 两字砸点当诗：`苦。` `咸的。` `沙沙。` `转了。`（偶尔可以，连续用就是腔）
- `也许是 X。也许不是。`
- `这就够了。`
- `你愿意把它当成…`
- 说明书、呼号、收据、空白自己会活、会睡、会播
- 场面写完后再加：`屋里只有你`、`听见自己的呼吸`、`窗帘拉着`、`字很小`、`人还在屋里`

同一套标题/正文不要复制给几十个旗标。共用模板也要写得像一件具体的事，不能写「有件事还没从你脑子里走」。旗标回声按主题簇（水/门/电台/邻居……）分写。

## 第二轮增补：收尾与模板

改旗标回声时发现的新毛病，和前面四条同级。

1. **不用破折号。** 不要拿「——」当语气停顿或揭示。能写成一句的写成一句，写不成一句的用句号断开。
2. **结尾落在动作或朴素结果上。** 事情做完就停。不让一件物摆着造型收尾：`桶里的水位线还在。` `黄还在眼角余光里。` `灰还在窗台。` 这类句子删掉，或者接一个人做的动作（「你把壶涮完，放回架上」）。
3. **枚举分支换成一件具体的事。** 模板要适配多个前置事件时，AI 会写「你加固过、封过窗、或者把鞋留在门外」把分支都列上，结果哪件都不像真发生过。宁可只写一件大多数人经历过的具体事，也不要三连「或者」。
4. **禁「没意义，但还是」。** `数字没有意义，你还是量。` `你知道会裂，你还是堵了。` 先否定再坚持是一种姿态，不是内容。把那个动作本身写具体（怎么量、量出什么），姿态就多余了。
5. **主语要当场能指出来。** `那次你碰过的东西还记得` ——谁记得？改成「你自己记得」。物件不当记忆和判断的主语。
6. **不堆同方向形容词。** `很冷，很黑，很安静。` 三个并列形容词是朗读腔。挑一个能改变下一步行动的来写（冷到被窝凉了→等心跳慢下来才躺下），其余删掉。

## 第二轮之二：单独成句的短陈述（2026-09-18 用户明确）

**这一条是上一节「两字砸点」的精确化。** 原来的说法（`苦。` `咸的。` `沙沙。`）只举了例，
没给可执行的判据，所以补写时常被漏过去。

### 判据：**一个「陈述」单独成句时，长度小于两个字绝对禁止，等于 3 个字要谨慎。**

关键是区分「**陈述**」和「**非陈述**」——判据不是字数，是**这句话在不在陈述一件事**。

| 类别 | 例子 | 判定 |
|---|---|---|
| **陈述**（在讲一个事实/状态） | `不渴。` `墙薄。` `天亮。` `水开了。` `她走了。` | ❌ **禁**。2 字以下是硬红线，3 字要谨慎 |
| **非陈述**（应答、让步、语气、招呼） | `也行。` `行吧。` `算了。` `知道了。` `谢谢。` | ✅ **允许**。它不是"陈述一件事"，是说话的语气 |
| **非陈述**（口语应答词） | `嗯。` `哦。` `好。` `哪儿。` | ✅ **允许**（但仍不宜连续用） |

**为什么陈述句短就坏**：陈述的功能是**承载信息**。两个字承载不了信息，只剩一个"砸点"的
节奏——读者读到的是作者在敲桌子，不是事情在发生。

**为什么语气词短就可以**：`也行。` 的功能不是承载信息，是**表态**。它短得自然，
因为它本来就是口语里的一个音。

**对照（同一段里，一个该禁一个该留）**：

> ❌ 不渴。还是烧了一壶。
> ✅ 不渴，可我还是烧了一壶。

> ❌ 墙薄。隔壁要是还有人，这会儿也跟我一样醒着。
> ✅ 墙太薄了，隔壁要是还有人，这会儿也跟我一样醒着。

> ✅ 也行。至少知道这楼不是只剩我一个。 ← 「也行」是让步，留

### 改法：把短陈述**并进上一句**，或**补足成完整陈述**

| 禁 | 改成 |
|---|---|
| `不渴。还是烧了一壶。` | `不渴，可我还是烧了一壶。` |
| `墙薄。隔壁……` | `墙太薄了，隔壁……` |
| `手抖。我扶着墙站了一会儿。` | `手抖得厉害，我扶着墙站了一会儿。` |
| `冷。夜里我把毯子全压上了。` | `冷得睡不着，夜里我把毯子全压上了。` |

**自检**：写完把每个句号前的句子数一遍字数。**2 字以下的，问自己"它在陈述吗"**——
在陈述 → 必须并进上一句或补足；只是语气 → 可以留。

## 第二轮之四：左页只写见闻，不写行动（★ 铁律，2026-09-18 用户指出）

事件正文（`body`）显示在日记本**左页「发生了什么」**，选项（`label`）显示在**右页「怎么应对」**。
**左页记的是事情，右页才是我做的事。** 所以：

> **玩家在正文里读到任何"我做了一个动作"，都要先问：这个动作是不是所有选项的共同前提？**
> - **不是** → 它属于某一个选项，**必须留在右页**，正文里不许出现
> - **是** → 可以作为既成前提留在正文，选项是在它**之后**再做决定

### 两种结构（改写前先归类，不能一刀切）

| 结构 | 正文里有什么 | 例 | 改写要点 |
|---|---|---|---|
| **A · 纯见闻型** | 只有**我看到的东西** | `surv_beat_mailslot`：「纸条上写着"还活着的敲三下"」 | 改人称即可，**任何行动都不许加进正文** |
| **B · 见闻+既成动作型** | 一个**已经发生过的**动作 | `surv_beat_boil_habit`：「你不渴，还是把一壶水烧开了」 | 这个动作是**所有选项的共同前提**（`既然开了就喝` / `倒回去`），可以留 |

### 反例（第一人称改写时最容易犯）

`surv_beat_mailslot` 的正文我一度改成：

> ❌ 上面写着"还活着的敲三下，需要水的写数量"……有人在。而且他还愿意花一整张纸来问。
> **我敲了三下。**

「敲三下」只属于 `knock` 这一个选项（另外两个是「写下数量，不署名」「什么都不做」），
它**不是共同前提**，所以是**在替玩家做决定**——玩家还没选呢，日记里已经记上了。

**正解**：正文停在**我看到的东西**和**它对我的意义**，把决定留给右页。

> ✅ ……有人在。而且他还愿意花一整张纸来问。
> （右页：敲三下 / 写下数量，不署名 / 什么都不做）
> （左页结果批注：我照着敲了三下，过了一会儿对面也回了三下，然后就再没有下文了。）

**唯一例外**：结果批注（日记本左页下方那行手写批注）**可以**写动作和结果——
那里本来就是"我做完之后怎么样了"。

### 自检

写完 body 后逐句问：**「这句话里，是不是有一个我在做某事？这个动作，三个选项是不是都要做？」**
只要有一个选项不做，这个动作就必须从 body 里挪走。

## 第二轮之五：不打比方（禁说书腔，2026-09-18 用户明确）

用户原话：

> 「太说书了，不够口语……谁会这样讲话啊，'等于拿喇叭喊'之类的类比句。
>  '靠，难道昨晚发电机的响声给他听到了吗' 这样才更偏向口语。」

### 判据

> **这句话我会不会说出口？** 说出口会别扭的，就是书面语。

人在心里骂人、发慌、犯愁的时候**不做类比修辞**。打比方、找喻体、把两件事并列起来
讲一个道理 —— 那是**作者的活**，不是**当事人的活**。

### 禁的（书面比喻 / 说书腔）

| 病句 | 病在哪 |
|---|---|
| `发电机响一晚上，等于拿喇叭喊"这有人，还有电"。` | 「等于 X」是**说理**，不是人心里的话 |
| `跟停电赛跑。` | 抽象 + 工整，像标题不像念头 |
| `蠢。真蠢。`（后接长篇推理） | 先下判断再论证，是评论员的口吻 |

### 允许的（口语里本来就有的）

`跟死了一样` · `像没头苍蝇` · `跟下饺子似的` —— 这些**人真的这么说**，因为它们已经
磨成了口语词，说的时候不过脑子。**区别在"有没有在打比方"**，不在"有没有比喻"。

### 正解参照

- ✗ `蠢。真蠢。发电机响一晚上，等于拿喇叭喊"这有人，还有电"。`
- ✓ `靠，昨晚发电机响了一整夜。` / `他是不是听见了。`

**后者的信息量一点没少**（发电机响了、可能暴露了），但它不是"想"出来的，是**慌出来的**。

## 第二轮之六：脏话尺度（★ 作者决定，2026-09-18 用户定档：**B 中等**）

第一人称日记的语料里必须有骂人的话，否则"会吐槽、会骂、会生气"就是空话。
但脏话的**档位**是作者决定，定死在这里，改文案时照着来。

### 三档定义（用户选 B）

| 档 | 内容 | 判断 |
|---|---|---|
| A 克制 | 只有 `靠` | 太软，强度 4 的崩溃场面撑不住 |
| **★ B 中等（采用）** | **`靠` / `他妈的` / `操`** | 是 |
| C 放开 | `操他妈的` / `狗日的` / 更脏的 | 过，会压过内容 |

### 按强度分配（照这个用）

| intensity | 允许的 | 例 |
|---|---|---|
| 1–2 | **`靠`** 起头，`他妈的` 偶尔 | `靠，昨晚发电机响了一整夜。` |
| 3 | `他妈的` 正常用 | `他妈的，又是这摊子事。` |
| **4** | **`操`** 可以出，**但全篇最多一次** | `操。` |

### 规矩

1. **低强度不出 `操`。** 强度 1-2 用 `操` 是廉价发泄，不像过日子的人。
2. **强度 4 的 `操` 一篇最多一次。** 骂第二遍就变成表演了，第一遍才是真的。
3. **`story` / `dream` 两类仍然收着用**（吐槽含量低）—— 死人旁边骂一句"操"会把气氛全毁掉。
   `ws_dead_radio_man` 全篇一个脏字都没有，这是对的。
4. **脏话落在句首做叹词，不做形容词。** ✓`靠，…` `操。` · ✗`这他妈的天气` ← 这是修饰，读起来像翻译腔。
5. **不用脏话替代信息。** `操，全完了。` 是空的。要说清**什么完了**。
6. **★ 脏话不是强度 3 的必备项 —— 有些场面骂了反而毁。**
   恐怖来自**冷漠 / 安静 / 反复琢磨**的场面（对方留人放哨、有人把警示牌扶正、
   一个人在屋里数警报），骂一句会把那种冷静冲掉。
   **判据**：这一段的力量来自"我害怕"还是"这件事本身可怕"？
   后者不骂。第一批里的 `pl_warning_corpse`、`nuke_arc_night_siren` 都是零脏字。

## 第二轮之七：禁倒装句（2026-09-18 用户明确）

用户原话：

> 「一些倒装句，全部禁止。例如：有人在门外撬 → 改为：有人在撬门」

### 判据

**主谓宾按正常语序摆。** 中文口语说「**有人在撬门**」，不说「**有人在门外撬**」。
把动词或宾语甩到句尾，是**书面强调**手法 —— 写的时候是有意识的，说的时候没有。

### 禁的形态

| 病句 | 正解 | 病在哪 |
|---|---|---|
| `有人在门外撬` | `有人在撬门` | 动词甩到句尾 ── 这是**文言/新闻标题**的强调，不是人说话 |
| `门口躺着个人，身上压着块纸板` | `门口有个人躺着，身上压着块纸板` | 主谓倒装 |
| `缝里漏进来一道光` | `一道光从缝里漏进来` | 宾语后置 |
| `街口那边响了三下枪` | `街口那边响了三枪` | 数量词后置 |
| `软的一下` | `踩上一软` / `踩下去软了一下` | 名词短语当状语 |

### 为什么这条要单列

倒装句读起来"有味道"，所以**改写时特别容易被吸引**（我在第一批里犯了一串：
标题 `有人在门外撬` `门口躺着个人` `缝里漏进来一道光` `街口那边响了三下枪`，
正文 `软的一下` `就一下`）。

它和「不打比方」是同一类病：**都是作者在句子外形上下功夫，而当事人不会这么说话**。
区别是打比方是加东西，倒装是挪位置 —— **挪位置同样能看出来是 AI 写的**。

### 自检

写完一句，把语序**还原成正常主谓宾**，读一遍。
如果还原后更顺、更自然 —— **原文就是倒装，改掉。**

## 第二轮之八：★ 口语化 ≠ 抽骨头（2026-09-18 用户指出，最严重一条）

用户原话：

> 「为什么有一些残酷事情的描写被缩减了？
>  原句：没人收尸，也没人从他身边绕路的时候多看。
>  问题句：没人收。也没人经过的时候多看一眼
>  这个尸为什么被你刻意省略了，导致句子变得很诡异」

### 病是什么

改第一人称时，我为了"口语化"把句子里的**具体名词和主语**磨掉了。实例：

| 原句 | 我改成的 | 磨掉了什么 |
|---|---|---|
| 没人收**尸** | 没人收 | **尸** ← 句子的重心从「这里有一具尸」滑到「没人管」，场景描写变成了人心评论 |
| 货架**已经被清过一遍** | 货架清了 | 被动 + 完成态 → 光秃秃两个词 |
| **你**把建材塞进门缝 | 建材塞进门缝 | **主语** → 变成施工记录，没有人在动手 |
| **土是冻的** | 土冻着 | **是……的**判断 → 变成状态词，少了"我挖过，我摸到的是冻土" |

**`没人收。` 这种句子不是含蓄，是信息缺失。** 读者要在心里自己补"收什么" ——
而这正是"读起来很诡异"的来源。

### 判据

> **口语的短，是"短但信息不省"，不是"短且省掉主语/宾语/关键名词"。**
> 丢掉了主语和具体名词的短句，不是口语，是**电报**。

对照：

| ✗ 抽了骨头 | ✓ 真口语 |
|---|---|
| 没人收。 | **没人收尸。** |
| 建材塞进门缝。 | **我把建材塞进门缝。** |
| 土冻着。 | **土是冻的。** |
| 货架清了。 | **货架已经被人清过一遍。** |

### ★ 特别警告：残酷场面的具体名词**一个都不许省**

`尸` `血` `冻硬` `臭` `烂` —— 这一版世界观靠这些词立住。
改写时最容易犯的错就是觉得它们"不雅/书面"而磨掉，**磨掉之后场面就空了**。

> **残酷场面里的直白名词是承重墙。** 只能写得**更具体**，不能写得更含糊。
> `没人收尸` 四个字里，`尸` 没有替代品。

### 与其它规则的冲突处理

`第二轮之二`（禁短陈述）与 `第二轮之八`（禁抽骨头）**方向相反，容易搞混**：

| 情形 | 该怎么办 |
|---|---|
| `不渴。` `墙薄。` —— **信息不足**的短陈述 | ❌ 并进上句 / 补足（第二轮之二） |
| `没人收尸。` `土是冻的。` —— **信息完整**的短句 | ✅ 留（第二轮之八） |

**区分点**：把它删掉，读者会不会漏掉一个**必须知道的事实**？
会 → 它是承重的，短也可以留；不会 → 那才是砸点。

### 自检

改完一句，问两件事：
1. **主语还在吗**（谁做的）？
2. **具体名词还在吗**（对什么做的、什么现象）？
两个都在，才允许短。少任何一个，先补回来再谈口语。

## 第三轮增补：标题先摆事实，物件要有一条线

来自 `ws_dead_radio_man`（守着收音机死掉的那条）的重写。标题改了三次才落地，三次正好是反面梯度：

| 版本 | 坏在哪 |
|---|---|
| 有个人守着收音机走了很久了 | 「走了」双解：人死了，还是他坚持了很久？读完不知道发生了什么 |
| 找水的楼上，守着收音机的人坐着没了 | 拿动作当定语去修饰地点（「找水的」修饰「楼上」），语法拧着，只交代了地点、没交代那里发生了什么 |
| 上楼找水，有个人守着收音机坐着没了 | 仍是给事实加一层「场合」包装 |

**落地的是「一具尸体坐在收音机旁」。** 标题只摆事实：一眼看见是什么，不给事实套壳。场合、动机、深意全部下沉到正文。

- **不要挂前置短语来交代缘由**（`上楼找水，…` / `去找水的路上，…`）。真要交代，正文第一句去交代，而且第一句不要逐字重复标题。
- **双解的字别用**（`走了`）。标题只被看一眼，歧义就是没写。
- **正文也不用对冲词**：`能找到的电池他大概都试过一遍` → `他全试过一遍`。写得比自己知道的确定一点，是这个嗓音的一部分。

**物件不能是清单。** 重写前的正文把椅子、小桌、收音机、墙上的纸、手里的纸条一样样摆开，每样都对，但玩家看完不知道这个人干了什么——**背后那条线（他每天按表开机，等无线电上有人回话，等到冻死）没写出来**。清单只管「有什么」，不管「因此在发生什么」。

- 一条线串起所有物件：他在等人回话 → 所以有那张写满开机的表、所以电池仓是空的（能找到的电池他都试完了）、所以手里还捏着明天的时间。
- **「他为什么这么做」让他自己留的字/物说，不要旁白解释。** 表上单独一行大字`有人听见就喊一声`是他写的——不用叙述者讲他有多执着。
- 最狠的细节（手里捏着**明天**的时间）必须有铺垫才扎得下去。

**日志禁止「事后顿悟」腔。** 这是「场面写完再补一句意义总结」的常见变体，句式是「做了 X，后来才想起来 / 总觉得哪里不对，原来是 Y」：

| 禁写 | 改成 |
|---|---|
| 你灌完水就出来了。下楼之后你总觉得哪里不对，想起来是那台收音机的调频指针，停在一个没有台的位置上。 | 你把水灌满就下楼了，桌上的东西一样没动，门带上了。从进门到出门你一直踮着脚，踩到楼下第一级台阶才把脚跟放下来。 |
| 走之前你看了一眼墙上那张表，最后一条停在上个月。 | 这些你都收进包里，剩下的壳留在桌上。 |

落点要么是**动作**，要么是**物理结果**。不要落在玩家的领悟上——领悟是玩家自己的事。

## 第四轮增补：对话直说、带心、无旁白（来自电台线台词返工，2026-09-15）

这一轮针对**对话型文案**（电台、聊天、选项 say）的四个新毛病。前三轮的规则继续有效，冲突处以本轮为准。

1. **口语直抒胸臆，不做二层推理。** 凡是读者要先补一条因果链才能懂的句子都是坏的：
   「够，够是够，烧之前得先算一笔账」——读者得自己推出"水脏→要烧→要省着用"。
   意图直接说明：「够。省着点用，能撑几天。」剧情确实需要隐喻的地方（揭晓、高潮）另算，
   日常对话里一个都不许有。
2. **台词必须带心，禁止零度报事实。** 「我妈咳了两声，我说快好了」是坏的——像别人在转述，
   没有情绪。人物说自己的事时要带上感受或无奈：「我妈咳得比前几天凶……我也只会说句快好了，
   说完自己心里都没底。」判断标准：这句话是不是**只有她在这个处境里才会这么说**。
   换个人说也成立的句子就是状况陈述，重写。
3. **禁「xx得xx」形容词套壳。** 「阴得难受」「灰得很」「闷得慌」是把形容词包了个壳，
   信息量为零。换成具体的量或行为：「天阴了四五天，雨一滴没下」「里面全是灰，拿布滤一遍才敢喝」。
   写完全文搜一遍「得」，逐个自查。
4. **正文严禁旁白。** 对话型文案里不许出现任何叙述层——那头的动静、停顿的时长、谁没说话，
   一律不写旁白行。要么进台词（她主动说：「我妈在那边缝东西呢，机器没电了，手缝的」），
   要么不写。停顿的呈现是引擎和 UI 的事（流式、分隔），不是文案的事。
   生成用的场景卡（环境、实情）不进正文，且必须标注「仅生成参考」。
   **唯一例外（2026-09-16 明确）：角色的「不在场」呈现。** 死亡 / 永久静默这种
   **没人能开口**的收场，可以有一行 `sys:'narrate'` 当作**收场标记**——它陈述的不是场面，
   是"这个频率不会再响了"这个事实。判定：**这句话有没有一个活人能说出来？**
   有 → 必须进台词；没有 → 才允许 narrate。
   ⚠️ 已加机器检查（`scripts/lint-content.ts`）：`narrate` **只许出现在以 `silence`
   收场的收尾轮里**，别处一律报错。

   反例（本仓库真实存在过，已改）：`xt_up` 的「四楼。楼道里一股烧过的塑料味，那扇门关着，
   门后有人。」——这是玩家的视角，电台里听不见，而且**它把"她隔着门问门牌"这句台词
   占掉了，玩家念门牌反而变得没来由**。改成她的台词「你到了？」「门牌 背面那个数 你念一遍」，
   旁白消失，选择也终于有了出处。

## 第五轮增补：好感度管「情绪朝谁」，不管「有没有情绪」（2026-09-16）

这一轮来自电台线的一次**概念性返工**：低好感那批台词被写成"冷、平、短、零度报事实"，
结果 AI 感比高好感还重。**用一个错误去防另一个错误。**

病根是一条写错的档位描述：`bond 1 =「短、平、报事实」`。
它把"**不向玩家表露**"误解成"**这个角色没有内心**"。

### 两级模型：一级情绪全线都在，二级表露才受好感控制

| | 一级：**人物的感受** | 二级：**对玩家的好感表露** |
|---|---|---|
| 是什么 | 怕、累、想爸、为猫难过、听见鸟叫心里一动 | 要陪伴、示弱、道谢、在意你怎么看她、留他 |
| 受谁控制 | **不受好感控制——全线都在** | **只受好感控制** |
| 怎么呈现 | 通过**事**透出来：她做了什么、提了什么、避开了什么 | 直接**对你说** |

**低好感 ≠ 话少。低好感 = 话不少，但没有一句是关于你的。**

### 可执行判据：替换测试

> 把句子里的「你」换成「**任何人**」，句子还成立吗？
> - **成立** → 这是**生活情绪**（朝世界、朝自己）→ **低好感也必须写**，写了才有人
> - **不成立** → 这是**对玩家的好感表露** → **只有高好感才能有**

| 台词 | 测试 | 结论 |
|---|---|---|
| 稠的顶饱 就是费水 **我妈还嫌我费** | 对谁都成立 | 生活情绪 → 低好感可用（**正例范本**） |
| 缸底刮了半天 刮出半桶 底下全是沙子 | 对谁都成立 | 生活情绪 → 低好感可用 |
| 我就剩一节了 **我妈前儿还开着收音机听戏 我说她她也不听** | 对谁都成立 | 生活情绪 → 低好感可用 |
| 你晚上把台开着呗 我听着好睡 | 换个人就不成立 | 好感表露 → **只给高好感** |

**反例（零度报事实，必改）**：

| 禁写 | 为什么坏 | 改成 |
|---|---|---|
| 缸里还有半桶 | 只报库存，没有这个人 | 缸底刮了半天 刮出半桶 底下全是沙子 |
| 我把灯关了 | 一个动作，没有情绪也没有处境 | 我把灯关了 摸黑坐着 反正开着也照不见什么 |
| 嗯 我知道 / 那当我没说 | 平静接受，不像被拒绝了的人 | 行 我知道了 / 那当我没说 你忙你的 |

### 推论：隐藏情绪是对**玩家**隐藏，不是对**读者**隐藏

前期人物"怕添麻烦、藏情绪"是对的设计。但**读者必须看得见**她在藏。
情绪靠**选材与定性**露出来，不靠宣言：

- **抱怨**（水有沙、我妈不听劝）→ 她在受累
- **自嘲 / 拟人**（猫嫌我没喂它）→ 她还有心气
- **认命口头禅**（反正开着也照不见什么）→ 她在给自己壮胆
- **护面子**（那当我没说 你忙你的）→ 她在意自己难看

**一句"我不怕"都不许写，但读者读完必须知道今天她过得很难。**

### 判决标准

| 想问的问题 | 归谁管 |
|---|---|
| 她今天过得难不难？有没有脾气？ | **不归好感管——低好感也必须写足** |
| 她愿不愿意让你知道她过得难？ | 归好感 |
| 她开口要东西了吗？ | 归好感（低好感宁可断粮两天才开口） |
| 她有没有因为你而高兴 / 害怕？ | 归好感（只有高好感才有） |

## 推荐写法

**标题**：现场观察，让人一眼知道发生了什么。只摆事实，不给事实套壳（不挂前置短语交代缘由、不用双解的字）。不要「事件：xxx」，也不要代词悬空。  
好：`楼下有人用喇叭念"战时征收"` · `半成品的工程你拧了两颗螺丝，手还在抖` · `一具尸体坐在收音机旁`  
坏：`征收的意义发生了变化` · `你碰过它了，手还在抖`（「它」是什么？） · `找水的楼上，守着收音机的人坐着没了` · `有个人守着收音机走了很久了`

**正文**：白描。谁、在哪、手上什么、什么触感——写成连贯的句子，不要两字砸点拼气氛。比喻可以留（如耳鸣像棉花），但要嵌在物上，不要单独当收束。

好：

> 她站得离门很远，只说要一杯水，给孩子。你从猫眼看见她手里空着。楼道里没有第二个人。

> 名单按门牌。他们说配合的给标记，不配合的以后再来。标记是一张黄纸，贴在门上。已经有两家开门了。

> 枪声过去了。枪身还带着淡淡的金属味，摸上去已经凉回铁的触感，可耳朵里那团「棉花」怎么甩也甩不掉。

坏（短句排比 / 故作高深）：

> 金属味。棉花还在，枪管凉了。

> 耳朵里空了一块。你甩头也甩不掉。

**选项**：动词 + 对象。`修门框` `留下半瓶水就走` `隔着门说没有`。不要 `把缝当作新的前提`。

**日志**：事后一两句，报告结果。已经写清楚的短日志不要加气氛尾巴。  
好：`你把鞋收回去。今晚不出。` · `枪管已经凉了，金属味还沾在指缝里；耳鸣没有跟着散掉。`  
坏：`你把鞋收回去，今晚不出，门口空出来一块。`（多出来的半句不改变结果）  
坏：`痕迹还在，人还在。` · `金属味。棉花还在。`

**情报 / 系统说明**：人名、数字、渠道。`5410 kHz`、`日薪一千二`、`六楼两居室`。不要升华。

第二人称「你」保留。短句可以，但短句里要有物；宁可写成一句完整白描，也不要连着砸点。

## 自检（写完问自己）

- [ ] 不看选项，只读正文，玩家能说出「发生了什么」吗？揭晓文要能说出是核爆、断电、洪水还是毒云。
- [ ] 标题是不是在给事实套壳（挂了前置短语交代缘由、用了双解的词）？把事实本身写成标题。
- [ ] 正文里的物件是串在一条线上，还是只摆了一排？读完能说出这个人做了什么吗？
- [ ] 日志落点是动作或物理结果，还是玩家的领悟？
- [ ] 有没有「不是 X。是 Y。」当开头？Y 如果不是具体物件，删掉重写。
- [ ] 有没有「X 也是一种 Y」或「X 是一种更长的…」？整句删掉，改成动作或结果。
- [ ] 物件有没有自己活、睡、播、承认、审判？改回物件就是物件。
- [ ] 选项是动作吗？日志是结果吗？
- [ ] 这段能不能和隔壁事件换标题而不露馅？能换就是模板，重写。
- [ ] **低好感段落**：每一句都过一遍**替换测试**（把「你」换成「任何人」还成立吗）？
      有没有哪句是零度报事实（只报库存/只报动作）？**低好感也必须写足生活情绪。**
- [ ] 低好感的情绪是不是**朝外/朝自己**（抱怨、自嘲、壮胆、护面子），而不是朝玩家表露？
- [ ] 有没有改 `id` / `effect` / `flags` / `requires` / `schedule`？那些不是文案。

## 本轮不管什么

- 不改数值、触发、选项效果。
- 旧内容里已经落地的句子不要为了「统一」抹平。
- 引擎注释、代码标识符不是玩家文案。

## 改稿须知（两个真源）

- 玩家看到的是 `src/game/copy/zh/events/*.ts`——`copy/hydrate.ts` 的 `pickCopy` **优先查文案表**；`content/events/*.ts` 里 `ch(..., { label })` 与 `effect.log` 的内联文字只是兜底。**两边都要改**：`npm run lint:content` 只查文案键存不存在，**不查两者是否一致**，只改一处会留下一份陈旧的。
- 「AI 味」的禁句表在 `scripts/lint-content.ts` 的 `CHEAP_VOICE_HARD`（`屋里只有你`、`听见自己的呼吸`、`这就够了`、`也是一种`、`人还在屋里`…）。命中只是 warn，但那张表就是本文档的机器可查版本，按红线用。
- 正文按段渲染（`body.split('\n')`），两套皮肤都随长度长高（档案皮肤 `art-nb-spread` 是滚动、不裁切），不必为长度硬砍，但也别比现有最长的那几条长出太多。
- 改完跑 `npm run lint:content` 与 `npx tsc --noEmit`；想确认实际渲染的是哪一版，用 `hydrateFamilies()` 打一遍。
