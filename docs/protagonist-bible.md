# 主角 · 公寓开局设定集

> 主角 = 玩家角色，第二人称"你"。这份文件只给氛围与事实，**不替玩家写性格**——玩家的人格由玩法表达。
> 灾前第 1-7 天是准备期（玩法完成），第 8 天崩溃日，收音机第 9 天开机。

## 502 的户型与朝向

| 项 | 内容 |
|----|------|
| 地址 | 3 号楼 1 单元 502（五楼东侧） |
| 楼栋 | 11 层，本小区最高的一栋，2003 年的板楼，有电梯（停电后是铁盒子） |
| 户型 | 两室一厅，一梯两户，楼上 602 长期空置 |
| 朝向 | 客厅大窗和主卧窗都朝**东**；厨卫朝北，卫生间无窗 |
| 阳台 | 南向，堆着住户自己的东西；灾前准备期的物资去向由玩法决定，此处不定 |

**东窗是电台线的物理前提。** 东窗正对小区中庭，中庭再往东就是 7 号楼。从五楼看过去：

- 7 号楼六层，比这栋矮。它的**四楼的窗和你差不多高**——看得见窗台，看不清玻璃后面。
- 白天能看清那排窗的格局；晚上只有哪扇窗亮不亮这一个信息（后期连这个都少）。
- 隔中庭直线约一百二十米。喊话听不清，但挥挥手能看见。这个距离是设计好的：**够不到，也断不了。**

## 楼栋与小区环境

- 小区是老小区，3 号楼是唯一的 11 层，其余都是 6 层矮楼。**7 号楼在最东边贴着北围墙**，围墙外那排门面里有"秀云裁缝铺"。
- 两栋楼之间隔着：一块铺透水砖的小广场、六张石凳、一排冬青、三棵老槐树、一排车位（灾后第 8 天起，车位上的车一辆一辆地没了）。中间没有遮挡——**白天从这栋走到那栋，两边楼上都看得见。** 这是营救与窗台交接要付的代价，不是顺手的事。
- 3 号楼内部：门禁第 8 天起就不关了。楼道声控灯没电之后，楼道只剩脚步声。谁家还亮灯、谁家已经搬空，五楼听得出来。

## 留居理由（职业映射）

留居理由是**背景事实，不是性格**。开场每人一句，按所选职业给：

| 职业 | 留居理由（一句话） |
|------|-------------------|
| 便利店店主 | 店就是命根。卷帘门后面还有半店货，人走了货就是别人的。 |
| 结构工程师 | 你算过这栋楼的受力。3 号楼是框架结构，塌不了——走，才是把命交给路上的运气。 |
| 急诊科护士 | 医院回不去，家离得近。你还留着这双手，就别在一个陌生的城市用。 |
| 退役军官 | 受过训练的人都知道：别在移动里死。这栋楼高、门多、看得远，先守。 |
| 囤积者 | 所有的东西都在这间屋里。走到哪都是空手。 |
| 数据分析师 | 矛盾的传闻还没分出真假。等信号给出结论之前，哪都不去。 |
| 长途货运司机 | 车在，但环城路堵死了，油也只够一次机会。机会要用在刀刃上。 |
| 中学化学老师 | 自来水厂停了之后，你知道这个城里还有哪几处水能处理了喝。走了就全作废。 |

## 末世开局时的资源处境

- 资源种类与数量由**职业 + 物资包**决定（见 `src/game/content/classes.ts`），本文件不定死。
- 既定事实（对所选职业一律成立）：
  - **电**：第 8 天起电网停了。你手上有电池和有限的自发电，游戏里以电量（kWh）计——收音机是电量的大客户。
  - **水**：市政水压一天比一天低，高层先停。5 楼不算高，但也没有余量。
  - **气**：停了。做饭靠电和存粮。
  - **人**：3 号楼灾前住着几十户，第 8 天之后少了一批——有连夜走的，也有从此不出门的。电梯口贴着的社区通知还剩半张。
- 留居不是安全，是选择。这条不写进文案，写进事件。

## 与小桃唯一的联系

第 9 天之前，你不知道东边那栋矮楼里住着谁。

- 手机没信号。对讲机没有。敲管子、扔绳子，跨着一百二十米的中庭和三排冬青，都做不到。
- 能越过这个距离的只有两样：**光**，和**收音机**。第 9 天你按开收音机的时候，两个都开始了——她看得见你这栋楼亮不亮，你听得见她说话。
- 这条线的规矩：**她知道你的楼，你先知道她的声音。** 房间号、她的脸、她的猫，都要靠事件一件一件挣来。
