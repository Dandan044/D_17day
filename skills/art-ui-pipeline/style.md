# 视觉与 prompt 备忘

从 `scripts/gen-art-*.py` 抽出来的可复用句子。新屏先抄这段，再写这一屏独有的物件布局。

## 正向风格

```
中国城市民防档案气质的写实摄影，暗调深灰蓝与墨黑，琥珀灯光 #e0a112，
胶片颗粒，纪录片。不要卡通，不要赛博霓虹，不要任何文字、字母、数字、水印。
```

静物可补：`旧牛皮纸文件夹、氧化钢板、档案室顶灯、克制、冷静、官僚机构的触觉感。`

## 负向

```
文字, 字母, 汉字, 英文, 数字, 水印, logo, 模糊, 卡通, 动漫, 赛博朋克,
人脸, 重复物体, 过曝, 白色背景, 鲜艳高饱和
```

场景再加：`两台售货机, 桌上放书`。独立静物再加：`纯白棚拍`。
天气板（窗外景，不带框）追加：`窗框, 窗帘, 窗台, 玻璃, 窗玻璃反光`——「从窗里看出去」这类写法会请来窗框，要写纯外景平视。

## 场景（要抠）

房间三件套模板：

```
超宽16:9一个房间，镜头平视，景深清楚。房间里只有三件东西，左右分开、互不重叠：
最左侧……；画面中后方……；最右侧……。混凝土地面，暗房间。无人。
```

桌面三件套模板：

```
超宽16:9，几乎正俯视的桌面特写，桌子占满画面。
桌面上清楚分开摆着三件东西，左右之间留出空隙，互不重叠、互不遮挡：
左侧……；中间……；右侧……。顶光偏暖。无人。纸上不要字。
```

**抠图友好性追加句（按需拼进模板）：**

- 受光均匀：`<物件>被吊灯完整照亮，整体受光均匀，没有大面积阴影压在物件上`——
  半张阴影的物品会被阈值后处理咬掉（蓝图右上半被咬成锯齿的教训）。
- 贴地留缝：`<物件>与桌面/墙面的交界清晰，物件底部与桌沿之间留出一条暗缝`——
  物品底边贴着桌沿时，检测框不得不切进物品或裹进桌沿。
- 主体材质：避免玻璃/半透明/高反光容器当主角（rembg 当背景透掉）；
  细长悬空件（天线、挂杆）要么不画，要么 `含完整的细长天线` 写明并配 keep_connected。
- 亮度分层：`地面/墙面比家具暗一档` 或 `侧光勾出家具轮廓`——
  暗家具贴暗背景时 u2net 会把两者当成一块。

## 独立物件（整图抠）

```
单独一件静物居中：……。深灰黑背景，琥珀侧光。
物件占画面约60%，四周留暗边以便叠加。无人。不要可辨认文字。
```

建筑模型：

```
建筑微缩模型，等距45度，同一比例，深灰桌面，博物馆射灯。
……。模型完整，四周留暗。无文字。
```
